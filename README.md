# 🧭 The Escape Journey: จากมนุษย์เงินเดือนสู้ชีวิต ➔ สู่ Full-Time Investor

**The Escape Journey** คือ Standalone Web Application และ Android Hybrid App (ขับเคลื่อนด้วย HTML5 + CSS3 + Vanilla JavaScript ผ่าน Capacitor) สไตล์ **16-Bit Retro Pixel Art** ที่จำลองการเดินทางต่อสู้ชีวิตจริงของผู้ใช้ — **"จากมนุษย์เงินเดือนสู้ชีวิต ➔ สู่ Full-Time Investor"**

ทุกองค์ประกอบถูกออกแบบตาม Character Bible จาก **Obsidian SecondBrain** เพื่อสะท้อนตัวตน วินัย และสร้างความพร้อมทางการเงินและการลงทุนอย่างแท้จริง

---

## 🎨 สไตล์ภาพ & ตัวละครหลัก (Character Bible & Mascots)
- **Retro 16-Bit Aesthetic:** โทนสีน้ำตาลไม้อบอุ่น ส้มอิฐ และทองคำ พร้อมจอเรโทร
- **ตัวละครหลักตรงตามข้อมูลจริง:**
  1. **MELO (ต๋อง):** ชายหนุ่มผมหยิกฟูดำธรรมชาติ (`#1B1B1B`), มีหนวดบาง, ผิวแทนอ่อน (`#F4C27A`), เสื้อยืดสีดำวง AC/DC พร้อมลายสายฟ้าสีส้มทอง, นั่งเทรด วางแผน และจิบกาแฟ
  2. **KUNGFU (กังฟู):** แมวส้มลายแท็บบี้ อกขาว อุ้งเท้าขาว และปลายหางสีขาวสะอาด จมูกชมพู ซน คล่องแคล่ว วิ่งเล่นบนโต๊ะและนอนทับคีย์บอร์ด คอยเตือนสติด้วยคำคมการลงทุนระดับโลก
  3. **OLEANG (โอเลี้ยง):** แมวสลิดขนสีเทาเข้มตัดน้ำตาล ดวงตาสีเขียวมะกอกปนน้ำตาล อ่อนโยน ขี้อาย นอนขดข้างโต๊ะ คอยส่งเสียง Purr และให้กำลังใจสู้ชีวิต
- **Active 60fps Canvas Animation:** ตัวละครหายใจ ขยับมือพิมพ์คีย์บอร์ด หางแมวแกว่ง กราฟแท่งเทียนในจอกะพริบ ควันกาแฟลอยละมุน และมีเอฟเฟกต์แสงไฟอบอุ่น

## 🧭 โครงสร้าง 4 โมดูลหลัก (Core Modules)

### 1. 🏠 ห้องพักใจ (The Living Hub & Room Evolution)
- **ระบบวิวัฒนาการห้อง 4 Stages:**
  - **Stage 1 (จุดเริ่มต้น):** ห้องสลัว มีกองบิลหนี้สินบนโต๊ะ โน้ตบุ๊กเครื่องเก่า บรรยากาศเหนื่อยล้า
  - **Stage 2 (เริ่มสะสม):** แสงแดดส่องผ่านหน้าต่าง กองบิลลดลง มีชั้นหนังสือและคอนโดแมว 2 ชั้นเพิ่มเข้ามา
  - **Stage 3 (ระบบลงตัว):** โต๊ะทำงานอัปเกรดเป็นชุด Workstation 3 จอ กราฟเขียวพุ่ง มีโมเดลรถสะสมบนโต๊ะ
  - **Stage 4 (อิสรภาพ):** ระเบียงกว้างเปิดรับวิวเมืองยามเช้า ป้ายไฟนีออนสีทอง **"FINANCIAL FREEDOM"**
  - *สามารถเลือกสลับดูพรีวิวแบบ Manual หรือเปิดโหมด Auto ให้ระบบปรับตามเกจความพร้อมจริง*
- **Interactive Speech & Audio:** คลิกที่กังฟูหรือโอเลี้ยงเพื่อเล่นเสียง Meow/Purr สังเคราะห์ และสุ่มเปิดคำคมให้กำลังใจ

### 2. ⚔️ หนี้ & ฐานราก (Debts & Investor Foundation)
- **🛡️ Dynamic Investor Readiness Gauge (0 - 100%):**
  - ประเมินความพร้อมสู่การเป็นนักลงทุนเต็มเวลา คำนวณจาก **ความปลอดหนี้ 40%** + **ฐานรากที่มั่นคง 60%**
  - ไม่ใช่แค่วัดเงิน แต่เน้นการเตรียมตัวสร้างเบาะรองรับ (Margin of Safety)
- **⚔️ ระบบติดตามหนี้สิน (Debt Tracker):**
  - ไม่มีข้อมูลเริ่มต้นบังคับ ผู้ใช้สามารถกดเพิ่ม/แก้ไข/ลบรายการหนี้และชำระยอดได้เองตามจริง 100%
  - แสดงแถบ % การชำระหนี้แต่ละรายการ เมื่อยอดคงเหลือเป็น 0 ฿ จะถูกประทับตราปลดหนี้และย้ายเข้าหอเกียรติยศ
- **🏛️ ฐานรากสู่ Full-Time Investor (Foundation):**
  - เพิ่ม/แก้ไข/ลบ รายการฐานรากได้ตามเป้าหมายชีวิต
  - รองรับ 2 รูปแบบ:
    1. **Monetary (คำนวณ % จากยอดเงิน):** เช่น เงินสำรองฉุกเฉิน 6-12 เดือน, พอร์ตหุ้นปันผลสะสมกระแสเงินสด
    2. **Checkbox (เช็กลิสต์เงื่อนไข):** เช่น หนี้ดอกเบี้ยสูงเป็น 0, มี Trade Journal 100+ ออเดอร์, ทดสอบระบบเทรดกำไรต่อเนื่อง 6 เดือน

### 3. 🏆 หอเกียรติยศ (Hall of Fame & Archives)
- จัดแสดงประวัติหนี้สินที่ชำระหมดแล้ว (`🏆 CLEARED!`) พร้อมยอดเงินและวันที่บันทึกสำเร็จ
- บันทึกฐานรากและหมุดหมายที่พิชิตได้สำเร็จ (`✨ ACHIEVED!`) เพื่อตอกย้ำความก้าวหน้าในชีวิต

### 4. 💡 คลังปัญญา & แมว (Wisdom & Cat Lore)
- **คำคมกังฟู (30+ Investment Principles):** รวบรวมแนวคิดจากนักลงทุนระดับตำนาน เช่น Warren Buffett, Charlie Munger, Peter Lynch, Ray Dalio, Howard Marks, Nassim Taleb ฯลฯ
- **กำลังใจโอเลี้ยง (30+ Life & Hustle Quotes):** ประโยคกระตุ้นไฟสู้ชีวิต เช่น *"รีบหาเงินตอนยังมีแรง ตอนแก่จะได้ไม่ต้องใช้ชีวิตที่ดิ้นรน!"*
- **จัดการข้อมูล (Data & Backup):** ส่งออกและนำเข้าไฟล์สำรอง JSON ได้ตลอดเวลา ปลอดภัย 100%

## 📱 การใช้งานบนมือถือ Android

### 1. ดาวน์โหลดไฟล์ APK โดยตรง
- ไฟล์ APK พร้อมติดตั้งถูกคอมไพล์ไว้ในโฟลเดอร์:
  - `The-Escape-Journey.apk` (ที่โฟลเดอร์หลัก)
  - `apk/The-Escape-Journey.apk`
- นำไฟล์ไปติดตั้งบนโทรศัพท์มือถือ Android ได้ทันที

### 2. ติดตั้งแบบ PWA (Progressive Web App)
- เปิดไฟล์ `index.html` บน Google Chrome ของ Android
- แตะปุ่มเมนู (⋮) ➔ เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)** หรือ **"ติดตั้งแอป" (Install app)**
- สามารถเข้าใช้งานแบบ Full-Screen โดยไม่ต้องใช้อินเทอร์เน็ต

### 3. Build APK ด้วยตนเอง
- รันคำสั่งใน PowerShell:
  ```powershell
  npm run build:apk
  ```
- สคริปต์จะซิงค์ไฟล์ไปยังโฟลเดอร์ `www/`, อัปเดต Capacitor Android และสั่งรัน Gradle เพื่อสร้าง APK ใหม่ทันที
