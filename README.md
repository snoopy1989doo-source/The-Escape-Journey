# 🎯 Project 2027: The Escape Journey (Interactive Life RPG)

**Project 2027: The Escape Journey** คือ Standalone Single-File Web Application (HTML5 + CSS3 + JavaScript ในไฟล์ `index.html` ไฟล์เดียว) ในรูปแบบเกมจำลองชีวิตกึ่ง RPG สไตล์ 16-Bit Retro Pixel Art ที่เปลี่ยนเส้นทางการต่อสู้ชีวิตจริงของผู้ใช้ — จาก **"ช่างไฟฟ้าโรงงาน ➔ สู่การปลดหนี้ครอบครัว ➔ สู่ Full-Time Trader ในวันที่ 1 มกราคม 2027"** ให้กลายเป็นการเดินทางที่เห็นพัฒนาการและให้กำลังใจตนเองในทุกวัน

---

## 🎨 จุดเด่นและสไตล์ภาพ (Visual & Mascot Specifications)
- **Retro 16-Bit / Warm Pixel Aesthetic:** โทนสีส้มอิฐ น้ำตาลไม้อบอุ่น เขียวมินต์ และเหลืองทอง พร้อมเส้นสแกน CRT ย้อนยุค (เปิด/ปิดได้)
- **ตัวละครหลักตรงตาม Character Bible (Obsidian Vault):**
  1. **MELO (ต๋อง):** ชายหนุ่มผมหยิกฟูดำธรรมชาติ (`#1B1B1B`), มีหนวดบางเท่านั้น, ผิวโทน `#F4C27A`, สวมเสื้อยืดสีดำวง AC/DC พร้อมสัญลักษณ์สายฟ้าสีส้มทอง, กางเกงบ็อกเซอร์ลายสก็อตสีแดงเข้ม (`#E74C3C`), เดินเท้าเปล่า
  2. **KUNGFU (กังฟู):** แมวส้มลายแท็บบี้ อกขาว ขาขาว ปลายหางสีขาวสะอาด จมูกและอุ้งเท้าสีชมพู ตากลมโต ซน คล่องแคล่ว วิ่งเล่นบนโต๊ะและนอนทับคีย์บอร์ด
  3. **OLEANG (โอเลี้ยง):** แมวสลิดสีเทาเข้มตัดน้ำตาล ดวงตาสีเขียวมะกอกปนน้ำตาล ขี้อาย อ่อนโยน นอนขดข้างโต๊ะคอม คอยส่งสายตาและเสียง Purr อบอุ่นให้กำลังใจ

## ⚙️ ฟังก์ชันหลัก 4 โมดูล (Core Modules)

### 🏠 โมดูลที่ 1: ห้องของ Melo (The Living Hub & Room Evolution)
- **HTML5 2D Canvas Engine:** แสดงห้องทำงานของ Melo แบบ Animated Pixel Art (ขยับมือพิมพ์คีย์บอร์ด, ควันกาแฟลอย, หางแมวส่าย, กะพริบตา, หน้าจอกราฟแท่งเทียนเคลื่อนไหว)
- **ระบบวิวัฒนาการห้อง 4 Stages:**
  - **Stage 1:** ห้องสลัว มีกองบิลหนี้บนโต๊ะ บรรยากาศเหนื่อยล้า
  - **Stage 2:** แสงแดดส่องเข้ามา บิลหนี้ลดลง มีคอนโดแมว 2 ชั้นเพิ่มมา กังฟูนอนเล่นบนคอนโดแมว
  - **Stage 3:** ห้องอัปเกรดเป็นโต๊ะ Workstation จอ 3 จอ กราฟเขียวพุ่งขึ้น และโมเดลรถ BMW โชว์บนโต๊ะ
  - **Stage 4:** ระเบียงกว้างเปิดรับแดดยามเช้าและวิวเมือง ป้ายไฟนีออนสีทอง **"FINANCIAL FREEDOM 2027"**
  - *สลับดูพรีวิวได้ทันที หรือเปิดโหมด Auto ให้ระบบคำนวณตามความก้าวหน้าจริง*
- **Speech Bubble & Petting:** คลิกที่ Melo, กังฟู หรือโอเลี้ยงเพื่อฟังเสียง Meow/Purr และอ่านคำพูดปลุกใจ

### ⚔️ โมดูลที่ 2: บอสหนี้ & เป้าหมายชีวิต (Boss Quests & Trackers)
1. **🩸 Boss 1: Mom's Freedom Shield (หนี้คุณแม่ / หนี้ก้อนสำคัญ):**
   - ผู้ใช้กำหนดและแก้ไขยอดหนี้ทั้งหมด (Target Debt) และยอดคงเหลือได้เองอย่างอิสระ ไม่มีค่าเริ่มต้นบังคับ
   - ระบบโจมตีบอส: กรอกยอดเงินที่จ่าย ➔ กดปุ่ม "โจมตีบอส!" ➔ เลือดบอสลดลงพร้อม Floating Damage Text, หน้าจอสั่นสะเทือน, เสียงฟันดาบ/ระเบิด
   - Combat Log บันทึกประวัติการชำระเงินทุกครั้ง
2. **🦏 Boss 2: Rhino's Crusher (หนี้ระยะสั้น & ค่างวด):**
   - เพิ่ม/แก้ไข/ลบ รายการหนี้ได้เองตามใจ (เช่น หนี้ TikTok, ค่างวดมอเตอร์ไซค์, หนี้นอกระบบ)
   - ปุ่ม "🔨 ทุบจ่าย": เอฟเฟกต์ค้อนพิกเซลทุบยอดหนี้แตกกระจาย พร้อมประทับตราปิดยอด
3. **🚗 Quest: Garage of Dreams (กองทุนดาวน์รถ BMW):**
   - ผู้ใช้กำหนดยอดเป้าหมายและยอดออมปัจจุบันได้เอง
   - ภาพพิกเซลอาร์ตรถ BMW สไตล์ 16-bit ที่ค่อยๆ เติมสี (Fill Color) ตาม % ความคืบหน้าเงินออม จนกลายเป็นรถสี M-Sport Blue เงางามพร้อมเปิดไฟหน้าเมื่อครบ 100%
4. **⏳ Reborn Countdown (1 มกราคม 2027):**
   - ตัวเลขนับถอยหลัง Real-time วัน : ชั่วโมง : นาที : วินาที สู่เส้นชัยอิสรภาพการเงิน พร้อมคำคมเตือนสติสลับเปลี่ยนทุก 12 วินาที

### 🧘 โมดูลที่ 3: จิตวิทยาและวินัยประจำวัน (Mindset Tools)
1. **🛡️ The 15-Minute Tilt Shield (ปุ่มฉุกเฉินดึงสติ):**
   - ปุ่มใหญ่สีแดงกดเมื่อรู้สึกหัวร้อน โดนลาก หรืออยากเอาคืนตลาด
   - กางโล่ทองคำพร้อมตัวจับเวลานับถอยหลัง 15 นาที
   - ข้อความเตือนใจ: *"ใจเย็นๆ นะต๋อง หนี้แม่ยังรอเราอยู่ อย่าเอาเงินค่าเหนื่อยทั้งเดือนไปเผาให้ตลาด"*
   - แถบสไลด์วัดระดับความอยากเทรด (Tilt Meter 1-10) พร้อมคำแนะนำตามระดับ
   - ช่องระบายอารมณ์และบันทึกประวัติ Tilt Log
2. **🌙 The 21:00 Abundance Ritual (3 สิ่งที่รู้สึกขอบคุณในวันนี้):**
   - กรอก 3 สิ่งที่รู้สึกขอบคุณก่อนนอน
   - เมื่อกดบันทึก: กังฟูเดินมาซบ มีหัวใจลอย และเล่นเสียง Purr นุ่มๆ จาก Web Audio API
   - ระบบนับ Streak วันที่มีวินัยต่อเนื่อง พร้อมเปิดดูประวัติย้อนหลังได้
3. **🛑 เช็กลิสต์กฎเหล็กเทรดเดอร์:**
   - เช็กลิสต์ดึงสติตัวเองก่อนกดเปิดออเดอร์ (เพิ่ม/ลบ/แก้ไขข้อความได้เอง)

### ⚡ โมดูลที่ 4: ลุยศึกเงินเดือน (The Payday Protocol)
- ออกแบบสำหรับรอบเงินเดือนโรงงาน (วันที่ 10 และ 25) โดยคำนวณจำนวนวันจนถึงรอบถัดไปให้อัตโนมัติ
- ผู้ใช้สามารถ **เพิ่ม/แก้ไข/ลบ รายการหักรายจ่าย หนี้สิน คืนเงินแฟน และเงินออมได้เองเสมออย่างอิสระ**
- คำนวณ **"งบกินอยู่รายวัน (Daily Allowance)"** จาก:
  $$\text{งบกินอยู่รายวัน} = \frac{\text{รายรับ} - \text{รายจ่ายจำเป็นทั้งหมด}}{\text{จำนวนวันจนถึงรอบเงินเดือนถัดไป}}$$

### 💾 โมดูลที่ 5: จัดการ & สำรองข้อมูล (Data Management & PWA)
- บันทึกข้อมูลทั้งหมดลงใน `localStorage` ของเครื่องผู้ใช้โดยอัตโนมัติ
- **Export Backup (JSON):** ดาวน์โหลดไฟล์สำรองข้อมูล `.json` เก็บไว้ได้ทุกเมื่อ
- **Import Backup (JSON):** โหลดข้อมูลเดิมกลับมาได้ทันที
- **PWA Ready:** รองรับการติดตั้งบนหน้าจอมือถือ (Add to Home Screen) ทั้ง iOS และ Android ทำงานแบบ Standalone และ Offline ได้ 100%

## 🔊 ระบบเสียงสังเคราะห์ (Web Audio API Synthesizer)
ตัวแอปใช้ Web Audio API สร้างเสียงเอฟเฟกต์แบบเรียลไทม์ภายในไฟล์ ไม่ต้องโหลดไฟล์ .mp3 หรือพึ่งพาอินเทอร์เน็ต:
- เสียงปุ่มคลิก 8-bit blip
- เสียงเหรียญ Coin chime
- เสียงดาบโจมตีมอนสเตอร์ Attack slash
- เสียงค้อนทุบหนี้แตก Hammer smash
- เสียงแมวร้องเหมียว Cat Meow
- เสียงแมวคราง Purr 26-30Hz
- เสียงกางโล่ทอง Tilt Shield
- เสียงชัยชนะ Victory fanfare

## 🚀 วิธีเปิดใช้งาน
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บน Google Chrome, Microsoft Edge, Safari หรือเบราว์เซอร์ใดๆ ได้ทันที
2. หรือใช้ Live Server / Web Server ในการทดสอบ
3. บนสมาร์ตโฟน: เปิดผ่านเบราว์เซอร์ แล้วเลือกเมนู **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อใช้งานเสมือนแอป Native ได้ทันที
